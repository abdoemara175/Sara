# Catalogue and AI Discovery Guide

The storefront’s AI typeahead reads the active Shopify catalogue at query time. It combines natural-language intent extraction with title, product type, tags, vendor, and description matching. This means products become discoverable without frontend changes once they are published to Shopify with consistent metadata.

The initial preview uses only two original demonstration products in accordance with the minimum-seed policy. They demonstrate `Skin Care` and `Make Up`. The interface nevertheless includes all eleven required storefront categories, each with a dynamic product count that grows from the live catalogue.

## Required taxonomy

| Storefront category | Recommended Shopify product type and tag |
| --- | --- |
| Make Up | `Make Up` |
| Skin Care | `Skin Care` |
| Hair Care | `Hair Care` |
| Body Care | `Body Care` |
| Baby Care | `Baby Care` |
| Instruments & Devices | `Instruments & Devices` |
| Nails & Oral Care | `Nails & Oral Care` |
| Female Intimate | `Female Intimate` |
| Shaving Tools | `Shaving Tools` |
| Hair Colors | `Hair Colors` |
| Other | `Other` |

For each product, set the Shopify product type and add the exact matching tag from this table. Add optional tags such as `Featured` or `Flash Sale` only where that merchandising treatment is intended. Publish the product to the Manus sales channel after adding media and a non-zero price; the storefront and AI search will then include it automatically.
